# Elvions Tech

Marketing site built with Next.js 15 (App Router), TypeScript, and Tailwind CSS.

## Getting Started

1. Copy `.env.local.example` to `.env.local` and adjust values as needed.
2. Run `npm install`
3. Run `npm run dev`

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript, no emit
